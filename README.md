# Stellarchy

A free-to-play browser game (formerly Three Hundred Suns): a neon 3D war for Sol and the 10 to 3,000 nearest real star systems. Players join rooms with a link and need no account.

- **Status:** planning. See `TODO.md`.
- `reference/` holds the claude.ai artifact version this grows from. Read it; don't edit it.
- `data/star_map.json` is Sol plus the 300 nearest systems, derived from the HYG Database v4.1 by David Nash (CC BY-SA 4.0).
